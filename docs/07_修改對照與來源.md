## 為什麼需要這些修改？

1. 其他小組沒有 API key 也能重現，課堂不受額度或搜尋服務影響。
2. 原三步圖即使資料不夠仍會結束；新增品質門檻與有界循環，對應第六章習題 5。
3. 原 AutoGen 角色描述中的「測試」不等於自動執行；新增可執行 QA，對應習題 2 的擴充方向。
4. 透過故障注入與停止上限，讓同學看到「不成功時如何正確結束」。
5. 移除本次不需要的線上模型初始化；沒有 .env 也不會啟動失敗。

## 與原版功能的差異

- 不執行即時網路搜尋，不回答真實天氣或最新價格。
- 不呼叫 LLM；不驗證模型理解、寫作或自主修正能力。
- 不保留對話 checkpoint；一次 run_case 是獨立實驗，不宣稱持久記憶。
- AutoGen 保留固定輪詢，沒有實作動態 speaker 回退。
- AgentScope／CAMEL 只作完整章節講解與短活動。upstream 裡的 requirements 僅保存教材版本參考，不能當成已安裝證據。

## 文件查證與需修正的讀法

- LangGraph node 可以是一般 Python，不必每個 node 都呼叫 LLM。根據 [官方 Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api)。
- AutoGen 的 UserProxyAgent 主要透過 input_func 取得人類輸入；description 不會自動執行任意程式。根據 [官方 agents API](https://microsoft.github.io/autogen/stable/reference/python/autogen_agentchat.agents.html)。
- [ReplayChatCompletionClient](https://microsoft.github.io/autogen/stable/reference/python/autogen_ext.models.replay.html) 是框架提供的固定回覆客戶端，適合這次重現協作順序的需求。
- 結構化輸出只處理所定義的約束；沒有寫在 schema／validator／控制邏輯裡的規則，不能宣稱它自動保證。

### 常見問題短答

**沒有 LLM 也算 Agent 嗎？** 本次是框架控制流程的離線測試；不宣稱已展示自主 LLM 智能體能力。

**為什麼只跑兩個框架？** 30–60 分鐘先完整比較四種設計，再用兩個互補案例深入實作，避免所有時間花在金鑰與套件安裝。

**兩筆來源就正確嗎？** 不一定，只是可觀察的練習門檻，且兩筆來自同一本教材。

**能不能接真的模型？** 能修改架構來接，但需另外驗證 API、額度與真實輸出；本次沒有完成這部分驗證。
